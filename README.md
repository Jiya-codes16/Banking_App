## 🏦 TRUST BANK


A simple and interactive banking management system built using Python, Streamlit, and Excel.

## 📌 About the Project

Trust Bank is a beginner-friendly banking application that allows users to create bank accounts, log in securely using their account number and PIN, manage their money, and view their transaction history.

The application uses an Excel file (bank_records.xlsx) to store bank account and transaction data.

## ✨ Features

- 👤 Create a new bank account
- 🔐 Login using Account Number and PIN
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- 📋 View transaction history
- 🆔 Automatic Transaction ID generation
- 📅 Automatic date and time recording
- 🎨 Interactive and animated Streamlit interface
- 🌈 Modern banking dashboard design

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenPyXL
- Excel
